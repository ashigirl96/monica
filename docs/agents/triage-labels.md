# Triage ラベル

スキルは 5 つの正準な triage ロールの名前で話す。このファイルはそのロールを、このリポジトリの issue tracker で実際に使うラベル文字列に対応づける。

| mattpocock/skills でのラベル | このリポジトリのラベル | 意味                                       |
| ---------------------------- | ---------------------- | ------------------------------------------ |
| `needs-triage`               | `needs-triage`         | メンテナがこの issue を評価する必要がある  |
| `needs-info`                 | `needs-info`           | 報告者からの追加情報を待っている           |
| `ready-for-agent`            | `ready-for-agent`      | 仕様が確定し、AFK の agent に渡せる        |
| `ready-for-human`            | `ready-for-human`      | 人間による実装が必要                       |
| `wontfix`                    | `wontfix`              | 対応しない                                 |

スキルがロール名で指示したとき（例:「AFK-ready の triage ラベルを付ける」）は、この表の対応するラベル文字列を使う。

実際に使う語彙に合わせて右の列を編集する。
