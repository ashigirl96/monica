# 落とし穴

外の道具の振る舞いのうち、知らないと間違えるもの。ここに置くのは、コードの 1 か所に結びつかないものだけ。1 か所に結びつくものは、その場所のコメントに書く。

## Bun

- `setTimeout` と `setInterval` は、2^31 ms（約 24.8 日）を超える遅延を 1 ms に丸める。遠い時刻は短い間隔の tick で今と比べて待ち、ユーザーが決める待ちには 2^31 ms より短い上限を付ける。
- `jest.useFakeTimers()` は `Bun.sleep` と `setTimeout` も止め、一部の timer だけを偽にできないので、HTTP の応答を待つテストが進まなくなる。
